## 範圍、風險與策略

最怕的失敗有兩種：

- 員工以為送出成功，實際上沒有存檔（G-01）。
- 不合法的申請被存了進去（G-02）。

規則全在後端，所以自動化測試以 API 驗收為主，一次涵蓋驗證、計算、存檔與查詢。天數計算是純函式，邊界多，用單元測試成本最低。按鈕鎖定、失敗後保留內容、純文字呈現屬於前端行為，以人工操作驗證。

- 天數算錯（高）：天數錯了，假單本身就是錯的。以單元測試（TC-02）加 API 測試（TC-01、TC-03、TC-04）驗證，對應 FR-05。
- 不合法申請被存檔或沒有回饋（高）：會違反 G-02。以 API 測試驗證，每個失敗案例都同時核對錯誤碼和筆數不變（TC-05、TC-06、TC-07），對應 FR-02～FR-06、FR-08、NFR-01。
- 客戶端竄改狀態或天數（高）：會破壞 FR-07 的不變量。以 API 測試驗證（TC-08），另加資料表約束的單元測試。
- 列出其他員工的假單（中）：會違反 FR-09。以 API 測試驗證（TC-09）。
- 存檔失敗卻被當成成功（中）：會違反 G-01。以替身讓寫入失敗，作為 TC-05 的變體驗證。
- 資料遺失（中）：違反 NFR-03。以重新開啟同一個資料庫驗證（TC-10）。
- 理由被當成 HTML 或 SQL 執行（中）：違反 NFR-02。API 測試驗證保存結果（TC-11），人工檢查畫面（TC-12）。
- 連點產生多筆、失敗後輸入消失（中）：違反 FR-10。以人工驗證（TC-12），因為主線沒有瀏覽器自動化。

**不測範圍**

- `invalid_body`、`invalid_type`：風險低，正常操作畫面時不會發生，列為已知缺口。
- 主管核准、額度、LLM：本次不在範圍（NG-01～NG-05），所以不建立模型 eval，也不做注入評測。
- 效能：沒有需求依據。

## 環境、資料與判定方式

- 指令：
  - Windows：`.venv\Scripts\python.exe -m pytest`
  - macOS／Linux：`.venv/bin/python -m pytest`
- 版本：Python 3.12，套件依 `course/01-上課/05-constraints.txt`。實際執行的版本在執行後記錄於追溯表。
- 隔離資料庫：每個測試用 `create_app(db_path=tmp_path / "test.db", today=date(2026, 10, 28))`，並以 `with TestClient(app)` 觸發初始化（SDS 測試注入）。conftest 斷言開發資料庫 `backend/data/leavebot.db` 沒有被測試建立（NFR-04）。
- 固定時鐘：注入 2026-10-28。SRS X-01 尚待講師裁定；如果改成 2026-10-12，只需改 TC-04 的輸入（見 TC-04）。
- 種子資料：E001 林小美、E002 陳大文、E003 張志豪（SDS S-03），每個暫存資料庫都會自動重建。
- 判定方式：
  - 預期值來自規格與人工算例，2026 年的星期都已核對。測試不呼叫 `count_leave_days` 來算預期值。
  - 錯誤以 `code` 和 `field` 判斷，不比對 `message` 的文字。
  - `days` 以數值相等判斷。
  - 每個失敗案例都要核對「錯誤內容」和「`leave_requests` 總筆數在送出前後相同」。
- Marker：每個業務測試標註 `@pytest.mark.req("TC-xx", "AC/FR 編號")`。

**基準合法申請**（以下簡稱「基準」）：

```json
{"employee_id": "E001", "leave_type": "annual", "start_date": "2026-11-02", "end_date": "2026-11-04", "period": "full", "reason": "家庭旅遊"}
```

### TC-01｜成功送出（AC-01.1、FR-07）

層級：API。這一層能一次驗到驗證、計算、存檔與查詢。前置資料：空的暫存資料庫。

1. POST `/api/leave-requests`，本文是基準。
2. 預期：回 201，`days == 3`，`status == "pending"`，`reason == "家庭旅遊"`，`employee_id == "E001"`。
3. GET `/api/employees/E001/leave-requests`。
4. 預期：回傳 1 筆，內容和第 2 步的回應相同。

執行方式：`backend/tests/acceptance/`。

### TC-08｜狀態和天數不能由客戶端指定（FR-07、S-01、ADR-03）
